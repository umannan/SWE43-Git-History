# SWE43 Grade Calculator

This repository contains a small grade calculator used to demonstrate
Git history and software evolution in SWE 43.

## Features

- Calculate average grades
- Calculate weighted averages
- Convert numerical averages to letter grades
- Validate grades and weights
- Display a student grade summary

## Running the Program

Run:

python3 grade_calculator.py

## Purpose

This repository is intended for educational use in SWE 43.
